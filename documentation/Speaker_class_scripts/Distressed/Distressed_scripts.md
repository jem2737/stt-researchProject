# Distressed Class

### Distressed Script 1:
[panicked voice] [breathing heavily] [broken pacing] [urgent] \
“Command— I need help now. I’m disoriented, I can’t see the exit, and I’m losing track of where the wall is. Somebody guide me out now!”

### Distressed Script 2:
[shouting] [gasping between phrases] [fearful tone] \
“I’m in trouble— I can’t keep moving like this. It’s too hot, I can’t catch my breath, and I need assistance right now, right now!”

### Distressed Script 3 — Two Speakers:
Speaker A (distressed):
[urgent] [breathing heavily] [panicked] [voice cracking or breaking slightly] \
“Help, I’m stuck in here— I can’t find the exit and I’m starting to panic. I need someone to answer me right now!”

Speaker B (normal):
[calm, steady voice] \
“I hear you. Stay where you are if you can, and keep talking so we can track your position.”
